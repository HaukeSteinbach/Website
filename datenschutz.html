If you use the project upload workflow, the personal data you provide there, including contact details, project information, and uploaded files, will be processed for project intake, communication, and contract performance. The legal basis is Article 6(1)(b) GDPR where the upload relates to pre-contractual steps or the performance of a contract, and Article 6(1)(f) GDPR for the legitimate interest in providing a secure file transfer workflow.

Uploaded project files are currently stored on the server file system in a protected upload directory. If the storage architecture changes in the future, this privacy policy will be updated accordingly.
